# Central Heater

A decoration and utility mod for Minecraft 1.21.1 on NeoForge.

Central Heater adds stoves, cauldrons, campfires, heat-related blocks, and practical utilities such as similar-stack controls.

## Compatibility

- Minecraft 1.21.1
- NeoForge
- JEI is optional

## Development

Use JDK 21, then run:

```sh
./gradlew build
```

Local Gradle caches, IDE settings, and Minecraft test-world output are intentionally ignored by Git.
